# Sticky Notes - Solarized 多機能付箋ツール

デスクトップ上に複数の付箋を自由に配置し、アイデアやメモを直感的に管理できる軽量な多機能付箋アプリケーションです。

Solarizedをはじめとする美しいカラーテーマ、多重起動防止、5世代にわたる自動バックアップローテーションなど、実用的な機能を備えています。

## 📌 主な機能
- **直感的な操作とスナップ移動:** ドラッグによる自由な移動やリサイズに対応。付箋同士や画面の端にピタッと吸い付く「スナップ機能」により、美しく整理できます。
- **多彩なスタイルカスタマイズ:** 
  - **3種類のカラーテーマ:** 🟢 標準 (Solarized) / 🔵 ダークナイト / 🟡 クラシック を右クリックメニューから瞬時に切り替え。
  - **フォント・サイズ指定:** 任意のフォント名（Meiryo, MS Gothic等）やフォントサイズ（5〜72）を数値で直接指定可能。
  - **不透明度調整:** 10%〜100%の間で付箋の透け具合を自由に調整。
- **📌 常に最前面表示 / 一時非表示:** 重要なメモを常に最前面にピン留めしたり、不要なときはトレイアイコンへ一時的に格納（非表示化）できます。
- **🔒 多重起動の自動防止:** ポート（50123）を使用した二重起動チェックを行い、アプリが重複して立ち上がるのを防ぎます。
- **💾 安全なデータ管理と5世代バックアップ:** 
  - メモ内容や配置位置（座標）を自動的・手動でJSONファイルに完全保存。
  - アプリ終了時に、過去5回分のデータを自動でローテーションバックアップ（`.bak1`〜`.bak5`）として退避し、データ消失を防ぎます。

## 🛠 動作環境
- **OS:** Windows (PythonおよびTkinter、Pillow、PyStrayが動作する環境)
- **Python:** 3.x 以降

## 🚀 使い方

### 1. 準備
本ツールは以下の外部ライブラリ（画像処理およびシステムトレイ常駐用）を使用します。コマンドプロンプトを開き、あらかじめインストールしておいてください。
```cmd
pip install Pillow pystray
```

### 2. ツールの起動
コマンドプロンプトからメインプログラム（例: `sticky_notes.pyw`）を実行します。
```cmd
python sticky_notes.pyw
```
あるいはファイラーからsticky_notes.pywをダブルクリック。

### 3. 操作手順
1. **付箋の追加:** 付箋のテキストエリアを**ダブルクリック**するか、右クリックメニュー（またはトレイアイコン）から「➕ 新しい付箋を追加」を選択します。
2. **メニューの表示:** 付箋上で**右クリック**すると、テーマ変更、フォント設定、不透明度、最前面ピン留めなどのカスタマイズメニューが表示されます。
3. **現状の保存:** `Ctrl + S` キーを押すか、メニューから「💾 現状を保存」を選択すると、現在のテキストと配置座標が即座に保存されます。
4. **終了とトレイアイコン:** 
   - 「👁️ この付箋を一時的に閉じる」を選ぶと、タスクバーを汚さずにシステムトレイに格納されます。
   - トレイアイコンの「👁️ 表示/非表示切替」をクリック（または左クリック）すると、すべての付箋の一括表示・非表示を切り替えられます。
   - 完全にアプリを終了する場合は、メニューまたはトレイから「🚪 アプリ終了」を選択します。
